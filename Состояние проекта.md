# Jornada Demo — состояние проекта

Дата: 8 сентября 2026 года. Версия 1.0.0.

## Что готово

- Оконное приложение на испанском языке: отчёты, сотрудники, конфигурация и справка.
- Выбор дня или периода, одного сотрудника либо всей компании.
- Детерминированная генерация отметок с отклонениями до 10 минут.
- Графики, разбитые смены, ночные смены, оплачиваемые и неоплачиваемые перерывы.
- Праздники Альмерии 2026, отпуска, больничные, отсутствия, разрешённые отсутствия и сокращённые дни.
- Отдельный необязательный файл сверхурочных.
- Индивидуальные PDF и общий отчёт с итогами по сотрудникам и дням.
- Проверки ошибочных данных и пересечений времени.
- Копии исходных Excel при каждой выгрузке.
- Переносимый комплект Windows x64 со встроенными Python 3.13.15 и библиотеками.

## Где находятся файлы

- `JornadaDemo` — папка программы, настроек и испанской инструкции.
- `JornadaDemo-Windows-x64.zip` — переносимый архив для Windows.
- `JornadaDemo/Informes/Ejemplo_septiembre_2026` — проверенные примеры PDF.
- `JornadaDemo/jornada/core.py` — чтение и проверка Excel, расчёты.
- `JornadaDemo/jornada/pdf.py` — PDF.
- `JornadaDemo/jornada/ui.py` — оконный интерфейс PySide6.
- `tools/create_config.mjs` — создание демонстрационных Excel через Artifact Tool.
- `tools/package_windows.py` — упаковка подготовленной папки Windows.
- `tests/test_core.py` — 21 автоматическая проверка.
- `tests/smoke_ui.py` — проверка кнопок, фильтров и фоновых операций Qt.
- `.build` — скачанные компоненты, окружение проверки на Mac и материалы визуальной проверки.

## Проверки

21 автоматический тест прошёл: расчёт месячной нормы по независимому ожидаемому
значению, совпадение дневных и месячных записей, диапазоны генерации за полный
год в обоих режимах, праздники, оплачиваемость перерывов, отсутствия, дата
приёма/увольнения, месячная смена графика, ночные смены, пересечения сверхурочных,
отсутствующий файл Extras.xlsx, некорректные данные Excel, PDF и копии конфигурации.

Через реальные элементы интерфейса Qt проверены навигация, выбор сотрудника,
дневной период, предпросмотр, создание PDF и отказ от выгрузки устаревшего
предпросмотра после изменения Excel.

Просмотрены изображения всех листов Excel, четырёх экранов программы и всех
страниц итоговых примеров PDF. Общий итог примера сентября: 390:36, включая
389:36 обычных демонстрационных часов и 01:00 сверхурочных.

## Практическое ограничение

Тесты проводились на Mac. В комплект включены Windows-библиотеки, но запуск
самого комплекта на Windows не проверялся. На Windows распаковать архив целиком
и запустить `Iniciar.cmd`. При проблеме — `Diagnostico.cmd`; для отдельной
проверки компонентов — `Verificar.cmd`.

## Открытые вопросы

Дополнительные вопросы о диапазоне отклонений, годе праздников и перерывах
отправлены пользователю. До ответа используются симметричные ±10 минут,
календарь 2026 и настраиваемые в Excel перерывы. Все вопросы, ответы и допущения
сохранены в документе «Вопросы и ответы — требования к программе.md».

## Продолжение разработки

Команды выполняются из корня репозитория в окружении Python с установленными
зависимостями requirements-dev.txt. Проверка расчётов (macOS/Linux):

```sh
PYTHONPATH=JornadaDemo python -m unittest discover -s tests -v
```

Проверка интерфейса без открытия системного окна:

```sh
PYTHONPATH=JornadaDemo QT_QPA_PLATFORM=offscreen python tests/smoke_ui.py
```

Повторно запускать create_config.mjs следует только при необходимости заново
создать демонстрационные настройки: он перезаписывает шесть Excel-файлов.
